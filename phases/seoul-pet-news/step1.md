# Step 1: 소스 확정 스파이크 — ✅ 완료 (2026-11-18)

## 목표
반려동물 공고를 긁을 **소스 1곳**을 확정한다. 코드는 쓰지 않는다. 판정 기준은 ① robots.txt 허용 ② 정적 HTML ③ 데이터가 실제로 충분히 있는가.

## 확정 소스의 사실 (Step 3·4 의 입력)

- 목록 URL: `https://www.seoul.go.kr/news/news_report.do?srchText=%EB%B0%98%EB%A0%A4%EB%8F%99%EB%AC%BC&curPage=N&bbsNo=158`
- **검색 파라미터는 `srchText` 만 먹는다** (`searchWrd` 는 무시되고 전체 64,415건이 그대로 나온다)
- 1페이지 10건, 총 22페이지. 행 = 번호 / 제목 / 담당부서 / 등록일
- **마감일 칼럼이 없다** (고시공고에는 있었다). 접수기간은 본문에만 간헐적으로 있다 (예: `11.18.~12.7. 모집`)
- 상세 링크가 `javascript:fnTbbsView('468820')` 이라 목록만으로는 URL 을 못 만든다 →
  **RSS(`https://seoulboard.seoul.go.kr/rss/RSSGenerator?bbsNo=158`) 로 형식을 확인했다:**
  `link = https://www.seoul.go.kr/news/news_report.do#view/470639` (해시, 번호 = `upperNo`)
  → **목록에서 번호만 뽑아 이 형식으로 조립한다**
- 첨부는 직접 URL 이 있다: `https://seoulboard.seoul.go.kr/comm/getFile?srvcId=BBSTY1&upperNo=470639&fileTy=ATTACH&fileNo=1&bbsNo=158` (이번 범위에서는 쓰지 않는다)
- 제목에 HTML 엔티티가 섞여 들어온다 (`&#40;` `&apos;`) → **디코딩 필요**
- 공공누리(KOGL) 표시는 확인되지 않았다. 저작권 정책 링크만 있다 → **본문을 저장하지 않고 제목·부서·등록일·원문 링크만 저장한다**

## 이 결과가 바꾼 것 (중요)

원래 기획은 **「우리 동네 반려동물 지원사업 공고」** 였다. 지원사업 공고는 구청에 있는데 **구청이 일반 봇을 막고**, 서울시 고시공고에는 2건뿐이다.
→ 기능을 **「서울 반려동물 소식·행사」** 로 바꾼다. 실제 내용은 행사·모집·교육·안전수칙이다 (예: 「서울펫림픽」, 「동물행복페스타 500팀 모집」, 「반려동물 폭염 안전수칙」, 펫로스 치유 프로그램).
→ **자치구 단위 매칭은 이번 범위에서 불가능하다.** 보도자료는 서울시 전체 단위다. 대상은 「서울 거주 사용자」로 축소한다 (Step 5).

## RSS 를 쓰지 않는 이유
최신 35건 안팎만 담고 **키워드 필터가 안 된다**. 217건은 검색 목록에만 있다. RSS 는 상세 링크 형식을 알아내는 데만 썼다.
